# Mathrushree Comforts — Demo Website

A demo website built for **Mathrushree Comforts**, a lodge on Acharya College Main Road, Chikbanavara, Bengaluru.

The rooms, tariffs and other details shown on the page are **sample placeholders**, included to demonstrate the design and layout. They are to be replaced with the lodge's actual rooms, rates and details in the final version.

Features of the demo: room showcase with sample tariffs, a "Book Direct" section, WhatsApp booking-enquiry buttons, amenities, and location/map section.
